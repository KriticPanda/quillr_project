About the quillR App

The quillR App is a project where we needed to implement things we learned during our final frontend module, React.
The App I choose to develop is one that you can go and read short stories and create your own, all the while you can comment on said stories, rate them with likes, edit or even delete them.

On this project, AI was used mostly for logic checks or syntax fixes, I used previous Labs, or lesson code alongs to implement the present features. Asides from that I did request the AI to generate media querries.
